# 종말 라디오 — 가중치·연계·천장 버전

GitHub Pages 자동 배포 설정을 포함합니다. 처음 올릴 때는 [GITHUB-PAGES.md](GITHUB-PAGES.md)를 참고하세요.

## 실행 / 업로드

프로젝트 폴더에서 `python3 -m http.server 8080 --directory dist` 실행 후 `http://localhost:8080` 접속. HTML 파일 더블클릭 대신 HTTP 서버로 실행하세요.
배포 대상은 `dist` 내부 파일 전체입니다. 업로드용 ZIP은 index.html이 최상단에 있습니다. 정적 사이트 호스팅에 해당 파일들을 업로드하면 됩니다.

## 용어와 흐름

- **이벤트**: 라디오에서 조우하는 방송 한 편. 가중치와 천장을 보유합니다.
- **행동 선택지**: 이벤트 안에서 플레이어가 누르는 버튼. 완료 조건, 천장 시작, 수집품 획득을 트리거합니다.
- 수신 시작 → 쿨타임 → 이벤트 추첨 및 표시 → 행동 선택 → 결과 기록 → 다음 쿨타임.
- 선택할 때까지 자동으로 넘어가지 않습니다. 기본적으로 이벤트는 반복 등장합니다.
- `once: true`인 이벤트는 행동 선택을 완료한 뒤 추첨에서 제외합니다. 현재 후보가 없으면 수신을 종료합니다.

## 데이터 작성: dist/events.js

```js
export const settings = { cooldownSeconds: 15 };
export const collectibles = [
  { id: 'map', name: '지도', description: '수집품 설명' },
];
export const events = [
  {
    id: 'intro', weight: 10,
    frequency: '89.1', title: '첫 방송', text: '방송 내용',
    choices: [
      {
        id: 'follow', text: '신호를 따라간다', result: '행동 결과',
        grantItems: ['map'],       // 선택 시 수집품 획득
        startPity: ['follow-up'],  // 선택 시 지정 이벤트의 천장 시작
      },
      { id: 'ignore', text: '머무른다', result: '다른 결과' },
    ],
  },
  {
    id: 'follow-up', weight: 3, once: true,
    requires: { choices: ['intro:follow'] },
    pity: { start: 'trigger', count: 3 },
    frequency: '104.7', title: '후속 방송', text: '방송 내용',
    choices: [{ id: 'ok', text: '응답한다', result: '결과' }],
  },
];
```

## 가중치 / 선행 조건

- 일반 추첨 확률 = 해당 이벤트 `weight` / 현재 등장 가능한 이벤트들의 `weight` 합.
- `weight: 0`은 추첨 제외입니다. 가중치는 0 이상의 유한한 숫자로 작성하세요.
- `requires: { events: ['intro'] }`: 해당 이벤트에서 아무 행동이나 선택 완료하면 해금.
- `requires: { choices: ['intro:follow'] }`: 해당 이벤트의 특정 행동을 선택 완료하면 해금.
- 여러 조건을 쓰면 **모두** 충족해야 합니다. 충족 전 유효 가중치는 0, 충족 후 원래 `weight`로 복원합니다.
- `requires` 생략 시 처음부터 해금됩니다. `pity.start: 'trigger'`만으로 이벤트가 잠기지는 않습니다. 트리거 전 조우도 막으려면 선행 조건을 함께 쓰세요.

## 천장 규칙

- 게임 시작 천장: `pity: { start: 'gameStart', count: 4 }`.
- 행동으로 시작: `pity: { start: 'trigger', count: 2 }`를 대상 이벤트에 쓰고 다른 행동의 `startPity`에 대상 id를 지정합니다.
- 카운트는 초가 아니라 **일반 이벤트의 등장 횟수**입니다. 선택을 기다리는 동안 줄지 않습니다.
- 카운트 2의 경우: 일반 등장(2→1) → 일반 등장(1→0) → 다음 방송에서 천장 대상 등장.
- 카운트 0으로 시작하면 다음 방송부터 강제 후보가 됩니다.
- 천장 0인 **해금된** 대상이 있으면 일반 이벤트는 제외하고 해당 대상들끼리 가중치 추첨합니다.
- 천장 강제 등장 회차에는 모든 활성 천장의 카운트가 줄지 않습니다. 동시에 0이 된 나머지 대상은 다음 방송에서도 강제 후보로 남습니다.
- 선행 조건이 잠겨 있으면 카운트가 0이어도 해금 전에는 등장하지 않습니다. 잠겨 있는 동안에도 일반 방송 등장에 따라 카운트는 줄어듭니다.
- 천장 대상이 일반 추첨에서 먼저 등장하면 해당 천장은 달성 처리합니다.
- 각 천장은 게임당 한 번만 시작합니다. 같은 트리거를 반복해도 초기화하거나 다시 시작하지 않습니다.
- 기본 가중치 0인 이벤트는 천장에서도 제외됩니다. 연계 이벤트는 양수 가중치와 `requires`로 설정하세요.

## 설정과 수집품

- 설정 창에서 기본 간격(1–3,600초)과 배속(0.5·1·2·4·8배)을 변경할 수 있습니다.
- 간격 변경은 다음 대기부터 적용됩니다. 배속은 남은 시간에도 즉시 반영됩니다.
- 설정 창 또는 수집품 창이 열려 있는 동안 쿨타임이 멈춥니다. 닫기 버튼과 Escape 모두 재개합니다.
- 수동 일시정지 상태에서 창을 여닫아도 수동 정지는 유지됩니다.
- 창을 열어 둔 채 새로고침하면 창은 닫히고 저장된 남은 시간부터 재개합니다. 수동 정지는 유지됩니다.
- `grantItems`로 지정한 수집품을 획득합니다. 같은 물건은 하나만 보유합니다.
- 미발견 수집품의 이름과 설명은 확인 창에서 가려집니다. 획득 결과는 수신 기록에도 표시됩니다.
- **수신 설정 → 진행 리셋**으로 기록, 완료 조건, 수집품, 천장을 초기화합니다. 간격·배속 설정은 유지합니다. 쿠키 삭제는 필요 없습니다.

## 저장 / 검증

진행은 브라우저 localStorage에 저장됩니다. 기기 간 동기화는 없습니다. 일반 대기 중 탭을 닫아도 실제 시간이 흐르며, 돌아오면 방송 하나만 도착합니다. 확인 창 또는 수동 일시정지 중에는 남은 시간이 보존됩니다.
이벤트·수집품 데이터를 바꾸면 별도 새 진행으로 시작합니다. 이전 순차 방송 버전과는 저장 형식이 달라 진행을 가져오지 않습니다.
최근 수신 기록은 최대 200개를 보존합니다. 그 이전의 완료 조건과 수집품은 유지됩니다.

`node tests/engine.test.js`로 검증합니다. 가중치 경계, 선행 조건, 천장 강제 및 동시 도달, 트리거, 정지, 배속, 저장과 수집품을 검사합니다.

수정 파일: `events.js`(콘텐츠/설정), `engine.js`(규칙), `app.js`(화면 연결), `index.html`/`style.css`(화면).

## 창가 디자인과 시간대

플레이어는 방송을 듣는 수사관입니다. 평범한 도시가 보이는 사무실 창가와 작은 라디오, 화분, 머그잔, 서류철을 SVG/CSS로 그립니다. 방송국 멤버들의 메모와 폐허는 배경에 표시하지 않습니다. 방송 도착 후 행동을 선택하기 전까지 라디오 주변에 만화 말풍선과 음표가 표시됩니다. 실제 오디오는 재생하지 않습니다.

`dist/sky.js`는 기기의 현지 시각을 사용합니다. 새벽 05–08시, 낮 08–16시, 노을 16–19시, 밤 19–05시로 창밖 하늘을 바꾸고 30초마다, 탭에 돌아올 때 갱신합니다. 실제 일출·일몰 시각이나 날씨 API는 사용하지 않으며 여우비 연출은 유지됩니다. 줄어든 동작을 설정한 기기에서는 비·음표 애니메이션이 멈춥니다.
